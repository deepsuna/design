사용 주의사항

값이 두 곳으로 갈라지지 않게 지키는 규칙

값의 원본은 피그마색·글자·간격 값은 피그마 변수가 원본입니다. 값을 바꿀 때는 피그마에서 바꾸고 tokens.json 을 다시 내보낸 뒤 node design/design-system/build.mjs 로 다시 생성합니다. tokens.json 을 손으로 고치지 않습니다.
구성표 guide.json프로덕트 · 포맷 · 진행 현황 · 히스토리 · 주의사항 · 홈페이지 규격 글은 design/design-system/guide.json 에서 관리합니다. 색·크기 같은 값은 넣지 않습니다. 히스토리를 추가하면 피그마 0 Overview › P8 운영 정보의 히스토리에도 같은 줄을 적습니다. tokens.json 의 브랜드·포맷과 어긋나면 빌드가 멈춥니다.
생성물은 손대지 않기이 갤러리(gallery/index.html · tokens.json · guide.json), design-system/dist/*.css, 사이트의 app/styles/tokens.css · figma-components.css · motion.css 는 생성물입니다. 고쳐도 다음 빌드에서 덮어써집니다. 손으로 고치는 파일은 layout.css · components.css · motion.css · guide.json 네 개입니다.
숫자 직접 입력 금지코드에 #007bff · 16px 같은 값을 직접 쓰지 않고 var(--color-text-brand) 처럼 토큰 변수를 씁니다. 직접 쓰면 브랜드·테마 전환이 깨지고 값이 두 곳으로 갈라집니다.
